## Proposals

### 1. ADOPT — transcript reading-position restore (ready-to-file brief)

gpui-kit #3922 (`message_scroller.scroll_to_offset` restores a saved reading position, merged 11-12 01:47Z) and NSH 0.5.0's own headline — "long conversations retain their scroll position" — pin the same law from two codebases in two days: **returning to a conversation restores where the reader was, not the live tail and not the top**. Our streaming transcript (500 ms flush into apps/web agent views) has no such concept — grep-verified 11-12: the only scroll-restoration in apps/web is router-level (`apps/web/src/router.tsx`); no transcript scroll-restore exists. Acceptance lines: (a) leaving a conversation mid-history and returning restores the reading offset; (b) the anchor is content identity (item id/offset), never an index — items that streamed in while away must not shift the restored position; (c) when the restored position sits above the live tail, an explicit scroll-to-latest affordance appears; (d) the saved position is per-device client state, never a server write; (e) a conversation opened at the live tail keeps today's behavior. Contracts-lane family (NEVR-530 addendum pattern); brief posted in the run comment; Talos decides whether to file.

### 2. WATCH (pre-registration) — desktop update honesty (NSH 0.5.0's updater/OTA model)

Stellarc's desktop shell has **no updater at all today** (grep-verified 11-12: no updater config in `desktop/tauri.conf.json`, no tauri plugin entries in `desktop/Cargo.toml`) — so this is a pre-registration for whenever desktop updates are chartered, sourced from NSH 0.5.0's model: **an update already running as a package is never re-offered** (the updater distinguishes installed app, runtime, and running package via `shellInfo()`); **OTA code-and-asset packages verify signatures and support trial launches with fallback**; **the engine warns when an installed OTA package can no longer run** rather than failing at launch. When the lane opens, these become acceptance lines for the Tauri updater plugin configuration.

### 3. WATCH — text-platform law extension + a11y day 5

The text-platform law pre-registered 11-10 extends with Rune's one-week clear of the three hardest problems: **an IME composition left mid-way becomes text, and the converting clause draws as a native field draws it** (#740); **Han characters take the forms and font of their language** (#745); **mixed-direction text reads correctly in static texts, Markdown, fields and fonts** (#725). For Stellarc the browser/Tauri webview supplies most of this — the law matters for any native-text surface and as an evaluation bar for every non-browser renderer this lane tracks. a11y batch, day 5: **a focused element names its active item for screen readers** (NSH #1727); **a label's text is exposed to AT** (gpui-kit #3937); plus two fail-visible laws worth pinning by pattern: **a picked file too large to read is reported, never dropped** (NSH #1790) and **a menu opens above its anchor when it doesn't fit below** (gpui-kit #3925). Fold with the next addendum brief; no standalone brief.
