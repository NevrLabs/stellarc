## Headline

1. **ACP's TypeScript SDK went 2.0 stable on 10-19, and the break lands on our exact code.** SDK 2.0.0 (npm 10-19 20:56, now 2.0.2) removes `AgentSideConnection`, `ClientSideConnection`, `Agent`, `Client`, `createLegacyAgent` and the connector helper — everything must move to `agent()`/`client()` apps with peer-context `request()`/`notify()`. Stellarc's entire ACP surface is two files, and both use a removed class: `apps/stellarc-node/src/runner.ts:297` (`new acp.ClientSideConnection`) and `tests/fixtures/fake-acp-agent.ts:63` (`new acp.AgentSideConnection`) — 13 `acp.*` references total, the other 11 being schema types (`SessionUpdate`, `ContentBlock`, `PermissionOption`, `PROTOCOL_VERSION`, `ndJsonStream`, …). Mitigating facts: the default protocol stays ACP v1 (2.0 does **not** force schema v2); unstable v1 features move behind the `@agentclientprotocol/sdk/unstable` entrypoint; and there is a published migration guide (`MIGRATION_STABLE_UNSTABLE.md`). The 1.x line's last publish is 1.9.0 (10-16, schema 1.26) — every publish since is 2.x, so dev+v4's pin (1.7.0, two minors behind even 1.x) is now on a frozen line. NEVR-129's "bump ACP" item is a migration, not a version bump. *(Brief below.)*
2. **The effect cohort moved: 4.0.6 and 3.22.4 both shipped 10-22.** 4.0.6 is a large patch (~30 entries) and matters to us in specific places: four reactivity/atom fixes (atoms dropping the latest success on async failure #9607, layer preservation through registry initial values #9313, atom finalizer-failure logging #9190, plus the new `skipInitialRun` option on `Atom.serializable`/`Atom.initialValue` #9522), an **EventLog remote-replay overhead reduction** (#9470 — the `eventlog` watch row's module is visibly alive), and blocking of nested internal-module imports in published exports (#9326 — a hazard only if anything imports `effect/*` internals; our tree doesn't). `@effect/opentelemetry`, `@effect/platform-bun`, `@effect/vitest`, `@effect/atom-react` all moved to 4.0.6 in the same cohort (core npm publish lagged the 03:25 satellite cohort by ~14h to 17:47 — the retired skew guard's "verify core resolves" rule still earns its keep). **effect/v4 pins 4.0.2** — three patches behind, and the merge into dev (still pending: dev 24 / v4 129 commits apart) should not carry stale pins. The v3 line's 3.22.4 has one quiet landmine: `Cause.Fail` now serializes under `error` instead of `failure` (toJSON/JSON.stringify/loggers) — dev pins 3.22.0 and is an event-log product; before folding, grep for consumers of serialized causes.
3. **PR #112 merged into `effect/v4` pinning @tanstack/db 0.15.0 + electric-db-collection 0.6.1 — and both went stale within days:** db 0.15.1 (10-18) *and* 0.15.2 (10-21) are on npm, electric-db-collection is at 0.6.3. 0.15.1 is the ordered-window correctness set the 10-17 report predicted (#2159 first-window synchronous publish, #2154 ordered-window repair after refetch, #2173 eager preload settle, #2172 adapter-collection GC, #2177 optimistic departures); 0.15.2 adds persisted-write row visibility (#2208) and hard `SerializationError` rejection for un-restorable rows (#2207). All patches, no API movement, zero `findOne`/`setWindow` call sites in our tree yet — fold cost is one pin pass on `effect/v4`. Also in the window: **Bun 1.4.4 (10-22)** — headline `bun fmt`, a built-in Prettier-compatible formatter (286× Prettier on Prettier's own repo, reads existing Prettier/oxfmt config; we're Biome, so it's toolchain-relevant, not a swap), plus pnpm-like peer resolution, ~3× faster warm hoisted installs on Linux, `Bun.SQL` PG-array params, and a security section — this re-arms the blocked NEVR-157 brief with concrete content.

Also: **drizzle-orm 1.0.0-rc.5 is real and installable** (npm 10-21 17:59, `rc` dist-tag; `latest` still 0.45.4) — first installable rc since rc.4, GA watch is live. Upstream's dist-tags include `effect` and `drizzle-effect` channels from their own Effect-integration experiments — when 1.0 GA lands, check whether an upstream Effect story replaces part of our owned `packages/drizzle-effect` bridge. And **Electric's repo has had zero commits since 10-06** (18 days; npm client 1.5.28 dates to 09-09) — the longest quiet spell since we started tracking; not a verdict change, but a maintenance flag worth a recheck next run.
