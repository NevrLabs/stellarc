### 1. ADOPT — keyboard-focus honesty laws for apps/web (pin §H in the lifecycle contracts)

**Precedent (Rune day-31 cluster, native ground, all merged 11-20/21):** one keyboard focus ring per focused element (#1296); the ring appears only when the keys put focus there (#1297 — `:focus-visible` semantics); a control disabled while focused hands focus on, never orphaning it (#1298/#1302); a roving group is one Tab stop (#1304); an overlay's custom ring composes with real keyboard focus (#1313); tooltips openable by keyboard focus and held while hovered (#1300). Corroborated by gpui-kit #3900 (roving Tabs keyboard nav), NSH #2694 (a rich editor's content box stays out of the Tab order), OpenHands #19729 (an open combobox listbox takes Escape before the dialog closes).

**Gap verified at effect/v4 head `e70393fc`:** apps/web/src carries exactly one `:focus-visible` CSS rule (`app.css:147`) and **zero** keyboard-focus/roving management in code (`tabIndex` grep: 0 hits in apps/web/src); the lifecycle contracts doc carries sections A–G with no keyboard-focus law. The F4/F5/F6/E5–E7/D2/C5 pattern applies exactly: pin the laws **before** the interactive surfaces (lists, toolbars, command surfaces, dialogs) are written.

**Work (docs-only, no app code):** add §H to `docs/design/agent-view-lifecycle-contracts.md` on effect/v4 — H1 keyboard focus is visually distinct from pointer focus (the browser's `:focus-visible` default is the floor; custom rings draw only for keyboard focus and compose with real focus, never replace it); H2 focus is never orphaned (a control disabled/removed while focused hands focus to a defined neighbour); H3 a roving group is one Tab stop (Tab enters the group, arrows move within, the browser's sequential focus never walks every row); H4 editing chrome stays out of the Tab order (content boxes and embedded editors are not Tab stops; their tooling is reached deliberately); H5 keyboard-reachable means keyboard-openable (anything hover-opens is focus-opens, and held-open follows focus as it follows hover). Each law cites its Rune/gpui-kit/NSH/OpenHands precedent and a pre-registered regression play in the house style.
