### 2. WATCH (new row) — Rune: the agent-native-verification datapoint, and what it pins for our own lane

Rune is not a candidate (pre-release, git-rev only, no release train; ADR 0013/0014 chose React web + Tauri 2), but it is the first framework to ship as a *primitive* what our ship-evidence contract (design brief 11-07) asks PR authors to do by hand: render the built UI headlessly, attach the PNG, and make the tree machine-inspectable. The actionable carry for apps/web is a wiring decision, not a dep: **when the ship-evidence contract lands, generate the evidence from the existing Playwright harness** (screenshot + axe tree of the changed surface, auto-attached on UI PRs) instead of relying on the author to capture it manually — the same primitive Rune puts in-framework, expressed with tooling we already run (Playwright is in the apps/web stack; the axe floor rides NEVR-150/#202). Rune also hardens the a11y-floor argument: "free until asked" lazy a11y-tree construction and dump-driven automation is the shape our axe assertions approximate. Track the repo; re-look on first crates.io release or 90 days.

### 3. Reference carry (no brief) — two GPUI Kit laws + the NSH endorsement

(a) **#3839 (reduced-motion timing law)**: when reduced motion is on, a transition that must land instantly still respects the element's timing semantics — reduced motion changes *how* motion resolves, never the timing contract. Goes into the apps/web motion acceptance lines when the first animated surface opens (motion is still not a dep). (b) **#3800 (keyboard-escape law)**: Tab/Shift+Tab must always be able to *leave* a focused DataTable — composite widgets may reorder and handle keys inside, but never trap sequential focus; add to the a11y floor's checklist alongside NEVR-150 when it rides the dev merge. (c) **#3844**: gpui-kit's homepage now recommends NSH — the native lane is consolidating into a two-repo platform (NSH shell + gpui-kit widgets); recorded in the NSH row so any future native/mobile re-charter evaluates the pair, not the parts.
