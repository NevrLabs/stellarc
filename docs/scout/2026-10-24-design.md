The 10-24 radar framing ("stale pre-merge runs, re-run/rebase to re-evaluate") is corrected accordingly. The remaining reds are the known non-blockers: `ui-typecheck-budget` (informational, continue-on-error) and `bundle-signed` (O2 Apple-cert secrets, ops).

**Second headline: shadcn shipped an official agent-first design-system linter — the tool-shaped answer to exactly this dilemma.** [`shadcn-ui/lint`](https://github.com/shadcn-ui/lint) (repo created 09-02, MIT, 3,263★, pushed 10-19; npm `@shadcn/lint` **0.2.3, 2026-10-19**) defines design-system rules whose error messages *teach agents the fix*: `no-restyle` (component owns its spacing/sizing; suggest size variants), `no-raw-colors`, `no-arbitrary-values`, `no-inline-styles`, `no-unknown-classes`, `require-static-classes`. Tailwind v4, shadcn not required, ESLint **and Oxlint**, React/Vue/Svelte. This converts "frozen by test" into "governed by contract" — the credible path to relaxing T02 for design-lane PRs without losing the pixel guarantees the desktop slice needs. TRIAL brief filed this run (proposal 1).
