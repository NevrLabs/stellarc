## Proposals

### 1. WATCH (pre-registration) — capability-grant acceptance lines for agent-authored rich content (gpui-kit v0.9.1 shell cluster)

gpui-kit's shell now hardens embedded script content the way an agent-native app must: **grants are enumerated** (network, execute, scheme), **unrestricted means an explicit `"*"`** (#3802), link targets are checked against scheme rules (#3804), script-supplied counts and nesting depths are bounded before native allocation (#3805/#3808/#3817), and ambient environment (proxy URLs) is never injected (#3810). Stellarc has **no such surface today — grep-verified against origin/effect/v4 @ a766835: no dangerouslySetInnerHTML, no iframe, no script injection in apps/web** (the sole `<script>` match is a comment). So this is a pre-registration, not a brief: when a rich-content surface is ever chartered (agent-published views, plugins, embedded previews), these five lines are the acceptance shape, and the ADR that covers it should cite the v0.9.1 cluster as precedent. Filed as a WATCH row; no Multica brief.

### 2. WATCH (pre-registration) — Rune's interaction laws as agent-view contracts addenda candidates

Four laws from Rune's 11-09 commits are ready to pin into the interaction/lifecycle contracts the next time an addendum brief is filed (the NEVR-530 pattern), not today: (a) **bidi/base-direction**: a paragraph's base direction comes from its first strong character (`Direction::Auto` first-strong), the caret seeks its drawn place, and Left/Right move across mixed-direction text as drawn (#339); (b) **tooltips are an explicit five-state machine** — idle, waiting, open, warm, suppressed — with a popup over the element hiding it until the pointer leaves (#383); (c) **undo joins typing commands** the way Chromium does, and IME composition is an explicit state, not a flag (#385); (d) **modal focus is an explicit state machine**, and keyboard focus is a first-class queryable state (#384). These join the existing motion/reduced-motion and keyboard-escape laws collected from GPUI Kit.
