### 1. WATCH (fold-by-pattern) — Rune #970 joins the snapshot-stability law family

**#970 (polled content stays still on a frame the user's input changed)** is the temporal half of a law we already carry structurally (Paseo #8916 snapshot identity — re-render scope = the changed row). The combined law for the agent-view contracts: *a snapshot update and a user input landing in the same frame — the input wins the frame; the polled change renders on a later frame, never visually displacing what the user just touched.* Fold as an addendum to the live-status & replay contract row with the next contracts addendum (design lane owns the vehicle). Same fold: gpui-kit #3978 (striped tables must not full-frame-redraw when rows don't fill) → the board-lane striped-row acceptance line (Multica #10575's class, now confirmed on native ground); NSH `addNodeView` (#2079) → editors-lane datapoint (a native rich editor converging on ProseMirror's extension shape).

### 2. WATCH — ADR 0015 post-merge evidence: the shell spectrum is converging from both ends

ADR 0015 is in-tree (effect/v4 `65fbe9a`). This week's evidence for its clients/arclet story, recorded for the first clients build: **NSH's embedding law now covers every platform it ships** (#2022/#2014 release runner → #2076 iOS runner → #2060 Android `libnsh.so` — a client pays only for the native features it reaches, at build time, everywhere), while **gpui-kit grew a `webview` crate** (#3986) — native shells embedding web islands, the mirror of Tauri's web-shell-native-edges. Whichever shape a Stellarc native client ever takes, the field's answer to "what does the client pay for?" is already *only what it reaches*. No brief; evidence note.
