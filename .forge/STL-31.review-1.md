After this PR applies 0002, the attribute lies. Fix expected: have `runMigration` return the applied (or verified) versions and annotate per entry — e.g. `yield* Effect.annotateCurrentSpan("stellarc.migration.version", applied.join(","))` — plus one assertion so removal goes red (span test or a returned-versions unit check). No current test can fail on this attribute (audit item 2 exception).
2. **`packages/contracts/src/identity/http.ts:460` — avatar success schema token deviates from §3 endpoint 26.** Spec: "`Schema-level: Uint8ArrayFromArray`". Implemented: `.addSuccess(Schema.Uint8Array)` (FromSelf — rejects array-encoded input that FromArray accepts; T1 handlers will hit this when returning JSON-array bytes). Fix expected: replace with `Schema.Uint8ArrayFromArray`.
3. **`packages/contracts/src/identity/http.ts:21-24` — `Permission` not validated against the permissions vocabulary.** §3 validation primitives: "`Permission = Record<nonempty resource, Array<nonempty action>>` validated against `packages/contracts/src/legacy/permissions` vocabulary". Implemented as unconstrained Record with a comment deferring to T1; the vocabulary exists (`legacy/permissions/index.ts` exports `statement` with board/project/task/label/organization…). Fix expected: constrain `Permission` keys to `keyof typeof statement`-derived literals and values to the per-resource action unions (Literal unions, not runtime better-auth calls), keeping empty-ceiling semantics for ApiKeyPublic; or, if genuinely deferred, that deferral must be an explicit spec change recorded on #15 before merge — as written it is a silent deviation.
