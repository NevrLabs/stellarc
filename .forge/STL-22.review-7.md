## DEFECTS

1. **MAJOR — CSP blocks every API-served avatar (§6 rendering identity).** `desktop/scripts/build-ui.sh:40` (sed) resolves only `connect-src`; `img-src` is absent and falls back to `default-src 'self'`. The frozen UI's `apps/stellarc-ui/src/lib/resolve-avatar-src.ts` rewrites `/api/…` avatar paths to absolute `VITE_API_URL` URLs and renders them as `<img src>` (sidebar, members, comments, inbox, repo PR heads). Inside the shell every one of those images 403s/blocks — screens render with holes the web suite never shows. **Fix:** build-ui.sh emits `img-src 'self' ${DESKTOP_API_URL} data:` in the resolved copy (source placeholder unchanged), and T10's test asserts the img-src directive contains exactly the baked origin.
2. **MAJOR — CSP blocks runtime-injected `<style>` elements (§6).** The frozen bundle injects styles at runtime: `comment-editor-*.js` (TipTap: `createElement("style")` + `innerHTML`) and `verify-otp-*.js` (input-otp `#input-otp-style`). `style-src` is absent → falls back to `default-src 'self'` with no `unsafe-inline` → WebKit ignores those style contents. Comment editor and OTP autofill styling degrade inside the shell only. **Fix:** resolved CSP gains `style-src 'self' 'unsafe-inline'` (script-src stays strict; Tauri nonces the index.html inline script at build time regardless), and T10's blanket `/unsafe-eval|unsafe-inline/` rejection is narrowed to script-src only, encoding the exact allowed policy.
3. **MINOR — T02 unit test cannot pass in the foundation CI job.** `tests/unit/desktop.test.ts:91-95` runs `git merge-base origin/dev HEAD`; `actions/checkout@v4` default depth-1 (foundation job, ci.yml:15) has no `origin/dev` ref — reproduced locally with a depth-1 clone: `fatal: Not a valid object name 'origin/dev'`, exit 128 → `expect(mb.status).toBe(0)` reds the moment foundation's PG-install step is fixed. Invisible today only because foundation dies earlier (infra). The standalone ui-purity job (fetch-depth 0) is fine. **Fix:** in the test, when `git rev-parse --verify origin/dev` fails, first spawn `git fetch origin dev` (networked CI) before merge-base — keep the hard fail if the fetch also fails.
4. **MINOR — launch-smoke health-probe grep races.** `desktop/scripts/launch-smoke.sh:93` greps `event=health-probe` immediately after window-created with no deadline/wait loop; the probe runs off-thread with a 2 s timeout, so a slow-but-alive origin can log after the grep. CI green today is timing luck. **Fix:** poll for the line with the same deadline pattern used for window-created (e.g. 15 s), then assert.
5. **MINOR — T06 has no CI execution evidence yet.** `maestro-desktop` is `skipping` behind `bundle-signed`, which fails closed on absent O2 secrets — by design, but it means the Maestro flow has never run against a real bundle on macOS/Windows (only YAML-parse assertions). Not fixable in-repo without the secrets. **Expected:** once secrets land, re-run the workflow and attach the maestro-desktop green run + desktop-boot screenshot to the PR before merge; treat "secrets landed but maestro still red" as a new rework.
